# Design System (`lib/design_system`)

## Purpose
Reusable visual component library for the enterprise application. Contains buttons, inputs, cards, dialogs, bottom sheets, snackbars, typography, spacing tokens, and micro-animations.

## Allowed Imports
- `package:flutter/...`
- `easy_ielts/core/theme/...`
- `easy_ielts/core/extensions/...`

## Forbidden Imports
- `easy_ielts/features/...`
- `easy_ielts/shared/...`
- Any API/Networking/Database classes.
